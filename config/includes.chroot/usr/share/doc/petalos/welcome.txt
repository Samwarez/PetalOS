PetalOS RC 1
===========

Default account: Petal
Password login for this account is disabled; the desktop starts automatically.

Temporary Files (RAM): ordinary home folders and temporary content.
Private Files: encrypted personal files, downloads and activity-related app state.
System Settings: encrypted VPN profiles and selected
desktop/app preferences. These remain available while Private is locked.

On new layout 2 media, OS and System Settings have separate encrypted partitions
and independent encryption keys. One SYSTEM passphrase prompt unlocks both at
boot. The OS is read-only and runs from RAM; updates preserve the entire System
Settings and Private partitions. Older cards require a separate migration.
Private still requires its own passphrase; administration uses a third credential.

Save Desktop Settings preserves supported desktop preferences. Save App
Preferences preserves only approved preferences and aMule's server list.
The OS supplies defaults when no saved preferences are available.

Crystal Dock is the bottom launcher/task dock. Right-click it to change its
appearance, then use Save Desktop Settings to preserve the layout. PetalOS
Helpers groups the storage, VPN and preference shortcuts. The XFCE top bar
remains available during the first trial. Start Crystal Dock in Applications
can restore it if it was closed. Use Thunar for Move to Trash; the dock's Trash
icon opens or empties the existing RAM Trash.

Wallpapers: System Settings/Wallpapers. The supplied library is added there
without replacing existing files. The default is 04-petal-drift.png; saved
desktop wallpaper and solid-color/gradient choices take precedence.
At boot, Esc shows the underlying log. A boot-error picture may appear beside
recent log lines; Space then returns to the boot console.

Files moved to Trash from Private are copied into RAM. Trash and its original
path metadata disappear on shutdown and when Private is locked, including idle
and lid/suspend locking. Restore needed files before locking. Large items can
exceed the RAM Trash limits; a failed copy keeps the original file.

VPN profiles: System Settings/Network/Profiles
Use the VPN profile manager to import and select a profile. Connect VPN and
wait for clock synchronization before launching network applications.
The VPN firewall stays active when disconnected.
Connect and Switch automatically test the tunnel, public IPv4/IPv6, VPN DNS
and clock. Results appear in the VPN manager and Conky. IPv6 failure is a
warning; required tunnel, IPv4 or DNS failures reject the connection.

Tor (RAM session) checks current VPN and clock readiness without an
administrator password. The OS includes its signed Tor Browser archive; no
manual archive installation is needed. Browser sessions stay in RAM. Downloads use assigned
folders in RAM or unlocked Private.

Test Video & Audio plays the bundled 12-second moving picture with left, right
and stereo speaker cues through the normal offline media player. It works
without network access or unlocking Private.

Ordinary USB drives appear in the file manager's Devices list. Select a drive
to mount it manually; automatic mounting is disabled. Administrator authorization
may be requested. Raw PetalOS boot/encryption volumes remain hidden.

SYSTEM passphrase: boot and desktop unlock.
Administrator password: privileged system changes.
Private passphrase: unlock Private Files using its separate shortcut.
Desktop unlock leaves Private locked. Manual and idle locking close Private.
Download mode can prevent idle locking; manual locking still works.

Offline app launchers isolate external networking. AppArmor additionally
confines the offline apps, Tor Browser, bundled Tor, and SAB's isolated viewer.
This does not confine every process or guarantee anonymity.

PetalOS is built from Debian trixie packages. Upstream package attribution,
licenses, archive keys, package sources, and compatibility identifiers remain
accurate. OS and bundled-app changes come through verified builds installed
offline, not a live updater. Tor payloads must be signature-verified.
